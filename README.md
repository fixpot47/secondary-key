# Secondary Key

A lightweight client-side Fabric mod for Minecraft 26.2 that lets you assign one extra key to any Minecraft keybind while keeping the original key working.

Example: Hotbar Slot 3 can stay on `3` while also being assigned to `Mouse 4`.

## Features

- One secondary key per Minecraft keybind
- Original key keeps working
- Supports keyboard and mouse buttons
- Client-side only
- Settings are saved automatically
- English and Russian translations

## Usage

Press **K** by default to open the Secondary Key settings screen. The menu key can be changed in Minecraft Controls.

Choose any action, press its Secondary Key button, then press the keyboard or mouse button you want to use. Use **Clear** to remove a secondary key.

## Requirements

- Minecraft 26.2
- Fabric Loader
- Fabric API
- Java 25
